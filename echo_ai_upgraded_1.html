Model routing

Paste one or many API keys (space or comma separated). ECHO detects the provider, checks each key with the provider and lists every model it can run in the picker at the top. Keys in echo_keys.json, .env or environment variables are picked up automatically. Saved is not verified: a key only shows Verified after the provider accepted it.

🔐 Secure server vault

Unlock the owner-only vault to store API keys encrypted on the server. Visitors cannot retrieve the actual keys.

Security: use the Secure server vault above for public deployments. It requires an owner password, encrypts keys at rest on the server, and sends only masked previews to the browser. The browser-only option is unencrypted and not recommended. Keep echo_keys.json, echo_vault.enc, .env, and all secret values out of source control.

Privacy: with no key, ECHO sends your message text to free third-party gateways (OVHcloud, Kilo, LLM7, and Pollinations/Wikipedia as last resorts). Start the server with ECHO_DISABLE_FREE=1 to never do that.
